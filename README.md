# Track Scout

Mac-App für DJs: Track Scout erkennt den laufenden Song in rekordbox oder Serato und schlägt passende nächste Tracks aus der eigenen Bibliothek vor.

**[Neueste Version herunterladen](https://github.com/iceclu/TrackScout/releases/latest)**

## Installieren

Voraussetzung: macOS 14 oder neuer.

1. Öffne die [neueste Version](https://github.com/iceclu/TrackScout/releases/latest) und lade unter „Assets“ die Datei **TrackScout-x.y.zip** herunter (x.y ist die Versionsnummer).
2. Öffne die ZIP-Datei per Doppelklick, falls sie nicht schon automatisch entpackt wurde.
3. Zieh **TrackScout** in den Ordner **Programme**. Das ist wichtig, damit Updates später funktionieren.
4. Öffne die App per Doppelklick. macOS meldet, dass die App nicht überprüft werden konnte. Klicke auf **Fertig**, nicht auf „In den Papierkorb legen“.
5. Öffne **Systemeinstellungen → Datenschutz & Sicherheit** und scrolle nach unten zu „Sicherheit“.
6. Klicke bei Track Scout auf **Dennoch öffnen** und bestätige mit deinem Passwort oder Touch ID.

Das ist nur beim ersten Start nötig. Die Warnung erscheint, weil die App nicht bei Apple notarisiert ist.

## Updates

Neue Versionen lädt Track Scout selbst im Hintergrund. Unten im Fenster erscheint dann ein Hinweis:

- **Installieren** aktualisiert die App sofort und startet sie neu.
- **Später** blendet den Hinweis aus. Das Update wird dann beim nächsten Beenden installiert.

Ein laufendes Set wird dadurch nicht unterbrochen. In den Einstellungen unter „Updates“ lässt sich das automatische Laden abschalten.
